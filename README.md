# ArmoMatt's Homebrew tap

```bash
brew install --cask armomatt/tap/ledge
```

| Cask | App |
|---|---|
| `ledge` | [Ledge](https://ledgeapp.vercel.app), a free notch app for the Mac: music controls, widgets and a shelf for files. |

Ledge updates itself, so `brew upgrade` leaves it alone (`auto_updates true`); the cask is bumped with each release anyway.
